## Brand

Display name: **Sarvadhara Travels** (wordmark: SARVADHARA TRAVELS).  
Hosting URL unchanged for now: https://sarisaitravels.netlify.app

## Contact (`assets/app.js` → `CONTACT`)

- `email` — shown + FormSubmit target (currently sarvadharatravels@gmail.com)
- `phoneDisplay` / `phoneE164` / `whatsappEnabled` — leave empty/`false` to hide; fill to re-enable
